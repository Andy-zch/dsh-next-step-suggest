# 下一句建议（next-step-suggest）

在 DSH 输入框里用灰字提示你下一句最可能发的话，按 `Tab` 填入草稿，**不会自动发送**。

轻量、低频：一条建议、两个键、三分钟一次。

## 怎么用

回合结束 → 等约 1 秒 → 输入框为空时灰字淡入：

| 按键 | 作用 |
|---|---|
| `Tab` | 把建议填入草稿（可编辑、`Ctrl+Z` 可退） |
| `Esc` | 本回合彻底闭嘴，不再出现 |

不想要就不要按，直接打字，灰字自己消失。

## 出现频率

这是这个插件最需要调的参数，逻辑全在客户端：

| 规则 | 默认 | 说明 |
|---|---|---|
| 触发条件 | 空闲 + 草稿为空 + 没有正在显示的建议 | 不是「回合结束那一下」，是条件满足就检查；打开旧会话也会检查一次 |
| 重试间隔 | 60 秒 | 一次尝试结束后（无论成败），至少隔 60 秒才再试 |
| 冷却 | 3 分钟 | 两次**显示**至少隔 3 分钟 |
| 会话上限 | 6 次 | 同一会话最多出现 6 次，之后安静 |
| 连拒 | 2 次 `Esc` | 连续忽略两次，本会话不再出现 |
| 接受后 | 60 秒 | 按过 `Tab` 一次，下一轮 1 分钟后就能再给 |

浮现发生在请求成功后约 1.2 秒，让你先把回答读完。

**为什么没出现？** 打开 F12，会有一行 `[next-step] skip: <原因>`，原因就是上面某一道闸门：`running` / `draft` / `hidden` / `showing` / `retry-gap` / `cooldown` / `session-cap` / `muted`。

## 什么时候会出现

全部满足才露脸：

1. 会话里至少一问一答
2. 当前回合刚结束（不是打开页面时）
3. 输入框为空、输入机空闲
4. 通过上面的频率闸门
5. 这一回合没被 `Tab` 接受过、也没被 `Esc` 关掉
6. 模型给了一句带具体对象的建议（「继续」「好的」这类空话会被直接丢掉）

任何一步失败都静默——不弹提示、不报错。

## 建议从哪来

**规则优先，模型兜底。**

状态里已经写明下一步时，不问模型，直接出：

| 状态 | 建议 |
|---|---|
| 有 `in_progress` 待办 | `继续 {该项}` |
| 只有 `pending` 待办 | `下一步 {该项}` |
| 计划激活中 | `按计划继续` |

规则没命中，才问模型——而且问的不是"用户会说什么"（那必然产出"继续"），是**"下一步该推进什么"**。建议语言跟着你最近一句用户发言走。

## 度量

F12 console 里搜 `[next-step] stats`，能看到这个会话的 `shown / accepted / dismissed`。只在接受或忽略时打印，出现时不刷屏。数据只在内存，重开即清零。

## 会话隔离

建议只属于发起它的那个会话。切走时在飞的请求会被中止，迟到的响应直接丢弃，不会显示到别的会话。

## 配置

在 profile 的 `cordis.patch.yml` 里改这一行（**覆盖会整体替换 config，没写的字段用默认值**）：

```yaml
- id: next-step-suggest
  name: '@local/dsh-next-step-suggest'
  config:
    enabled: true        # false = 完全静音，不用卸载
    rules: true          # false = 不走规则，一律问模型
    candidates: 1        # 1–3；改成 3 会一次要三句（界面仍只显示第一句）
    maxTokens: 120
    temperature: 0.9
    provider: ''         # 空 = 跟随会话自己的模型
    model: ''
    reasoningEffort: ''  # 空 = 不指定
    dedup: true
    timeoutMs: 6000
```

改完要 `remove_bundle` + `install_bundle` 重新加载宿主模块。

## 已知限制

- 频率常量写在 `client.js` 顶部（`MIN_INTERVAL_MS` / `MAX_PER_SESSION` / `DISMISS_STREAK_LIMIT`），要调就改常量再重装。
- 双面板（主对话 + 侧边对话）同时打开时，不遮蔽原生占位符，灰字可能与其重叠。
- 服务端模块有 ESM 缓存：改完代码必须重装或重启，刷新页面只换客户端。

## 卸载

`plugin_manager remove_bundle`，或从 `cordis.patch.yml` 删掉那一行。所有注册都在 `ctx.effect` 里，卸载后输入框零残留。
